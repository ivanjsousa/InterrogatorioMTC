# Interrogatorio MTC

This application provides an interactive form built with [Flet](https://flet.dev) for collecting information during a Traditional Chinese Medicine (TCM) interview. To run the app, make sure the `flet` package is installed and execute `main.py` with Python:

```bash
pip install flet
python main.py
```

All saved data will be stored inside the `dados_interrogatorio` folder.
